## How I work

- **The schema first, then the shape of the API, then the screen.** Most of the cost of a system
  lives in a decision made in the first hour of the data model.
- **Small, reviewable commits with the tests next to the behaviour**, so a reviewer can read one
  idea at a time and roll back one idea at a time.
- **I support what I ship.** I have installed the software, reset the machines and trained the
  people who use it, so I write for the person on the other end of the ticket.
